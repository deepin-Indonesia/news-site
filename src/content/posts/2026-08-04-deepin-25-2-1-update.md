## Sorotan Utama deepin 25.2.1

Berikut lima area utama yang diperbaiki pada update minor ini:

| Area | Yang Berubah |
| --- | --- |
| **Intelligent Search** | File Manager dan Global Search kini mendukung pencarian file dengan frasa bahasa natural |

## Intelligent Search: Cari File dengan Bahasa Natural

Fitur paling menonjol di deepin 25.2.1 adalah **intelligent semantic search** pada **File Manager** dan **Global Search**. Anda kini bisa mencari file lokal dengan frasa yang terdengar natural, misalnya:

- *"financial spreadsheets modified yesterday"*
- *"design images on the desktop"*
- *"downloaded installers"*
- *"PDFs from WeChat"*
- *"videos larger than 1 GB"*
- *"documents edited yesterday"*

Sistem akan menerjemahkan ekspresi tersebut menjadi kondisi terstruktur seperti **time**, **type**, **location**, **source**, **action**, dan **attributes**, lalu menggabungkannya dengan pencarian yang sudah ada: **filename search**, **content search**, dan **OCR search**. Artinya, Anda tidak perlu lagi mengingat nama file — cukup ingat ciri-cirinya.

## Peningkatan File Management dan Search

Selain intelligent search, komponen pencarian juga diperkuat:

- Update komponen **file indexing** dan **document parsing** untuk meningkatkan stabilitas pencarian nama file, pengambilan isi dokumen, dan pembaruan indeks
- Optimasi **image text search indexing** agar pencarian gambar berdasarkan teks di dalamnya lebih stabil
- Optimasi penanganan **DVD+/-RW disc erase** untuk operasi optical media
- Perbaikan pada **Recent files**, **SMB authorization**, **external storage**, dan skenario **partition encryption**

## Peningkatan DDE Desktop Experience

Sisi desktop juga tidak ketinggalan. Komponen **DDE** yang diperbarui meliputi **Control Center**, **system daemon**, **network core**, **clipboard**, dan **UI system update** — semuanya menyentuh pengalaman pengaturan, jaringan, update, dan clipboard sehari-hari.

Selain itu, detail interaksi desktop di **Control Center**, **Launcher**, **keyboard status**, dan **touchpad pages** turut dioptimalkan.

## Aplikasi Bawaan dan Runtime Linyaps

Sejumlah aplikasi umum mendapat pembaruan untuk memperbaiki tampilan, interaksi, dan stabilitas:

**Document Viewer**, **Image Viewer**, **Album**, **Font Manager**, **Calendar**, **Camera**, **Log Viewer**, **Input Method Configuration**, **Package Installer**, dan **Voice Notes**.

Yang tak kalah penting, **Linyaps runtime** diperbarui ke **v1.13.8** untuk meningkatkan instalasi, tampilan, startup, dan kompatibilitas runtime aplikasi Linyaps. Fondasi runtime aplikasi juga diperkuat melalui update **Qt6**, **Qt6 Wayland**, **Qt6 SVG**, **Qt6 Declarative**, dan modul kompatibilitas Qt6.

## Update Sistem, Kompatibilitas Hardware, dan Keamanan

Area ini mencakup perbaikan yang paling terasa saat melakukan upgrade:

- Perbaikan masalah **backup dan upgrade** pada **Immutable System**
- Update komponen kompatibilitas **printing**, **scanning**, **fingerprint**, **wireless**, dan **graphics**
- Penambahan dukungan perangkat wireless **ath12k** melalui update **linux-firmware**
- Integrasi sejumlah **security fix** untuk **glib2.0**, **OpenSSH**, **CUPS**, **ffmpeg**, **OpenVPN**, dan lainnya

## Cara Update ke deepin 25.2.1

Jika Anda sudah menjalankan deepin 25.2.0, update ini tersedia melalui **Control Center**:

1. Buka **Control Center** lalu masuk ke **System Update**
2. Klik **Check for Updates** untuk memuat daftar pembaruan terbaru
3. Pilih **Update Now** dan tunggu proses unduh serta pemasangan selesai
4. **Restart** perangkat untuk menerapkan seluruh perubahan

Bagi pengguna baru yang ingin memasang dari awal, image ISO deepin 25 dapat diunduh di [os.deepin.id](https://os.deepin.id).
